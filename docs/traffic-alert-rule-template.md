# 流量统计告警规则模板

> 流量进度条的数据来源。**每台要显示流量进度条的服务器，都需要一条启用的流量统计规则**，规则里没有的服务器前台不会显示进度条。

## 添加位置

后台 → **告警** → **新增规则**，按下面表单逐项填。

## 表单怎么填

| 表单字段 | 填什么 | 示例 |
|:---------|:-------|:-----|
| 名称 | `流量统计 · 服务器名` | `流量统计 · US` |
| 类型 | `transfer_all_cycle`（周期流量统计） | |
| duration | `10` | |
| min | `0` | |
| max | 流量上限（字节） | 1.2TB = `1288490188800` |
| cover | `1（忽略所有，选择特定服务器）` | |
| 服务器ID | `{"服务器ID": true}` | `{"4":true}` |
| cycle_start | 计费周期起始时间 | `2026-04-28T00:00:00+08:00` |
| cycle_interval | `1` | |
| cycle_unit | `month`（月流量） | |
| 通知组 | 默认通知组（或你的通知组） | |
| 触发模式 | 仅一次 | |
| 告警时要触发的任务 | 可留空，或填任务 ID，逗号分隔 | `1,2,3` |
| 恢复后要触发的任务 | 可留空，同上 | `1,2,3` |
| 启用 | 勾选 ✅ | |

## max 字节换算表

| 配额 | 字节数 |
|:-----|:-------|
| 100GB | `107374182400` |
| 150GB | `161061273600` |
| 500GB | `536870912000` |
| 1TB | `1099511627776` |
| 1.2TB | `1288490188800` |
| 2TB | `2199023255552` |

## 高级 JSON（表单自动生成，一般不用手填）

填完表单，底部的"高级 JSON"会自动生成，结构如下：

```json
[{
  "type": "transfer_all_cycle",
  "max": 1288490188800,
  "cycle_start": "2026-04-28T00:00:00+08:00",
  "cycle_interval": 1,
  "cycle_unit": "month",
  "duration": 10,
  "cover": 1,
  "ignore": {"4": true}
}]
```

保存后，前台对应服务器卡片下方就会出现流量进度条。
